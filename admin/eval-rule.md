# 채점 기준 (eval-rule.md)

> 이 파일은 **시스템 관리자**가 사전에 작성/수정합니다. 채점 LLM 3명은 매 문항마다
> 이 기준 전문(全文)을 그대로 전달받아 평가합니다. 점수 척도는 **0–100점**입니다.

## 점수 척도

- **90–100점**: 모범답안과 사실상 동일하거나, 핵심 개념을 정확하고 완전하게 설명함.
- **70–89점**: 핵심은 맞지만 일부 누락/부정확/표현 미흡이 있음.
- **40–69점**: 부분적으로만 맞음. 중요한 개념 일부가 빠지거나 오류가 섞여 있음.
- **1–39점**: 관련은 있으나 대부분 틀렸거나 핵심을 놓침.
- **0점**: 무응답, 무관한 답변, 또는 명백히 틀린 답변.

## 채점 원칙

1. **모범답안 대비 정확성**을 최우선으로 본다. 사실 오류는 강하게 감점한다.
2. **표현 차이는 허용**한다. 단어가 달라도 의미가 맞으면 감점하지 않는다.
3. **완전성**을 평가한다. 모범답안이 요구하는 핵심 요소가 빠지면 비례하여 감점한다.
4. 사용자가 모범답안에 없는 내용을 추가했더라도, 그것이 정확하고 관련 있으면 감점하지 않는다.
5. 채점은 **일관성** 있게 한다. 같은 품질의 답변에는 같은 점수를 부여한다.

## 출력 형식

각 심사위원은 다음 JSON만 반환한다:

```json
{ "score": 0-100 사이 숫자, "rationale": "간단한 채점 사유" }
```
